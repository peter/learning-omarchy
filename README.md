# Learning Omarchy

## VS Code

Installation:

- Open the Omarchy Menu by pressing Super + Alt + Space (or Super + Space depending on your version).
- Navigate to Install > Editor.
- Select VSCode from the list to begin the installation.

If you want VS Code to open automatically for your files, you can set it as your system-wide default editor by navigating to Setup > Defaults > Editor within the Omarchy settings
